# Validação visual — ficha de Caçador

- A rota `/ficha-cacador` foi renderizada em desktop com a ficha, a importação de ficha JSON, os controles de recursos, atributos, perícias e o painel de arquétipos.

- A navegação lateral foi compactada para manter a entrada **Ficha Caçador** visível junto às demais áreas modulares.
